# ХОД 0.28 · Texel + Caissa · Android ARM64

Локальный шахматный помощник для тренировок и разбора: распознавание доски официальных приложений Lichess и Chess.com, история, стрелка, намёки и устойчивое плавающее окно. Android 10–16, ARM64. Только стандартные шахматы.

## Что изменилось

В 0.28 добавлен режим **«Скрывать при касании»**. При касании игры скрываются стрелка, ход, оценка и варианты; панель, захват и история остаются активными. Подсказка не возвращается от того же кадра, снятия выделения или позднего ответа движка. После реального хода скрытие снимается, а следующая рекомендация появляется только на своём ходу. «+ → Вернуть подсказку» восстанавливает её вручную. Режим включён по умолчанию и отключается в настройках или «+».

Android может передавать касание вне панели с нулевыми координатами: тогда скрытие срабатывает на любое такое касание, а не только на фигуру. Если событие не пришло, распознанные точки возможных ходов служат запасным сигналом. Они по-прежнему не становятся пешками и не изменяют историю. На телефоне нужно отдельно проверить доставку событий и темы без точек. Новых разрешений, перехвата ходов или монитора root-ввода нет.

В проверку близких альтернатив Caissa добавлены легальные размены на одной клетке: защищённый ферзь всё равно не подходит для размена на пешку. Учитываются связанные фигуры, превращение и en passant. Если расчёт проверки превышает 128 узлов, альтернатива отклоняется. Текущий результат показывается из актуального кеша, чтобы запоздавший промежуточный PV не заменил итоговый ход на экране.

Сохраняются возможности 0.27:

- Добавлен **Texel 1.12** со встроенной официальной нейросетью и штатным `UCI_LimitStrength` / `UCI_Elo`. Caissa 2.0 остаётся вторым явно выбираемым движком. Stockfish, Maia, API и ONNX не возвращались.
- В настройках и «+» доступны движок, сила и формат помощи: «Точный ход», «Близкие варианты», «Намёк без хода».
- Texel сам ограничивает силу. Дополнительный случайный выбор поверх него не применяется. В Caissa режим близких вариантов может выбрать другой проверенный PV с небольшой потерей оценки; оценка берётся от выбранного хода.
- При шахе, оценке мата, недостаточной глубине и обнаруженной непосредственной опасности Caissa сохраняет свой итоговый ход. Это ограниченные проверки, а не гарантия отсутствия ошибок.
- Намёк скрывает координаты хода, варианты и стрелку. Вместо них показывается проверяемая подсказка: шах, атака на ферзя, взятие, рокировка, превращение или направление поиска. Это не полное стратегическое объяснение.
- Первый переход с версии 0.26 и старше выбирает **Lichess → Texel → Умеренный → Близкие варианты**. Прежний максимальный уровень не переносится на новый движок. Затем выбор сохраняется. Истории платформ, свой цвет, тема фигур, подпись и координаты панели сохраняются.
- Исправления распознавания меток ходов, подсветки шаха, приёма законного `bestmove` без PV, мини-кнопки и положения окна сохранены.

Помощь движка в партиях с людьми запрещена Lichess и Chess.com при любой силе. Нет режима защиты от бана, подгонки под 100/100 или гарантии человеческого стиля. Для Lichess см. https://lichess.org/page/fair-play. Используйте разрешённые тренировки против встроенного компьютера и разбор завершённых позиций; игра с чужим BOT-аккаунтом не равна встроенному AI.

## Рекомендуемые настройки

| Настройка | Для начала |
| --- | --- |
| Платформа | Lichess |
| Движок | Texel 1.12 |
| Сила | Умеренный; если слишком сильно — Лёгкий |
| Формат | Близкие варианты; для самостоятельного поиска — Намёк без хода |
| Профиль | Блиц 3+2 — 600 мс; рапид 10 минут — 1500 мс |
| Память | 128 МБ |
| Скрывать при касании | Включено; «+ → Вернуть подсказку» для возврата вручную |
| Положение окна | Закреплено, автоперенос выключен |

| Сила | Texel | Caissa |
| --- | --- | --- |
| Лёгкий | UCI_Elo 1600 | 2000 узлов + выбранное время |
| Умеренный | UCI_Elo 1900 | 12000 узлов + выбранное время |
| Максимальный | Без ограничения силы, выбранное время | Без ограничения узлов, выбранное время |

Числа UCI_Elo — внутренняя шкала Texel, **не измеренный рейтинг Lichess**. Ни один уровень не гарантирует конкретную точность, рейтинг или отсутствие зевков. Ограниченный Texel по своей архитектуре использует один поток; на максимальном уровне доступны выбранные 1–4 потока. Caissa использует выбранное число потоков. Узловой лимит может немного превышаться из-за периодических многопоточных проверок остановки.

«Точный ход» означает итоговый ответ выбранного движка при текущем уровне, а не автоматическое включение максимальной силы. «Близкие варианты» для Texel сохраняет его штатное ослабление; для Caissa включает три варианта и осторожный выбор среди близких оценок. «Пересчитать · до 8 с» не отключает уровень силы. Процент «распознавание» в окне относится к чтению доски, а не к точности шахматных ходов. Профили выбираются вручную, часы не считываются. Распознавание и первая загрузка процесса добавляют задержку.

Оба движка получают полный известный исходный FEN и историю ходов. Смена уровня очищает память расчёта; смена движка завершает старый процесс и создаёт выбранный. При этом подтверждённая история приложения сохраняется. При восстановлении с середины история до подтверждённого FEN неизвестна. Ошибка запуска явно показывается; скрытого переключения на другой движок нет. У APK нет разрешения `INTERNET`.

## Обновление через Termux

Скачайте `Hod-v0.28-Touch-Hide.zip` в Downloads. Распаковка ZIP не удаляет прежние файлы, поэтому выполните очистку:

```bash
cd "$HOME/hod-likesomments" &&
unzip -o "$HOME/storage/downloads/Hod-v0.28-Touch-Hide.zip" &&
python3 scripts/clean-legacy.py &&
git add -A &&
git commit -m "v0.28: hide advice on touch and guard exchanges" &&
git push origin main
```

Push запускает **Actions → Build Android APK**. Скачайте артефакт **Hod-Android-arm64** с `app-release.apk`. Постоянная подпись прежняя: менять `HOD_KEYSTORE_BASE64` и `HOD_KEYSTORE_PASSWORD` не требуется. APK устанавливается поверх приложения с тем же сертификатом. При несовпадении подписи Android откажет в обновлении; не генерируйте другой ключ. См. [docs/SIGNING.md](docs/SIGNING.md).

## Использование

1. Выберите платформу, цвет, движок, силу и формат помощи.
2. Разрешите окно поверх приложений и захват всего экрана. Для выбранного Root-захвата подтвердите запрос в менеджере root.
3. Откройте начальную расстановку, разместите панель вне доски. Подтверждение требует двух стабильных кадров.
4. Цвет меняется «Белые ⇄ / Чёрные ⇄» в заголовке. На чужом ходу подсказки нет.
5. «↘» сворачивает панель в маленького коня; нажатие возвращает её. Перемещение мини-кнопки не переносит сохранённое место большой панели.
6. «+» открывает движок, силу, формат, профиль, паузу и пересчёт. «↻» проверяет текущую доску или распознаёт новую начальную расстановку. «Позиция» восстанавливает подтверждённый FEN с середины.
7. Касание игры скрывает подсказку до изменения подтверждённой позиции. Она снова появляется на следующем своём ходу. Вернуть раньше: «+ → Вернуть подсказку».
8. В режиме намёка самостоятельно выберите ход. Чтобы вернуть точные координаты и стрелку, смените формат в «+».

Если панель перекрывает доску, анализ ждёт перемещения или сворачивания. При перетаскивании фигуры требуется стабильная законная расстановка после отпускания. Потеря захвата оставляет причину остановки. Прошивка может завершить процесс: разрешите фоновую работу ХОД в настройках realme. Абсолютная устойчивость окна и отсутствие всех багов не заявляются.

## Сборка и проверки

Actions: Java 17, Gradle 8.13, SDK 36, NDK r28c, CMake 3.31.6, ARM64/NEON/API 29, статическая libc++, ELF 16 KiB. Release lint, постоянная подпись и настоящие Linux-протокольные тесты обоих движков обязательны.

- Caissa 2.0: commit `bb725799e9b19ebdaa0d584f5433fc1c3019e349`, официальная сеть `eval-ml-8-152B-spsa.pnn` с опубликованным GitHub SHA-256.
- Texel 1.12: commit `bd5698c67f3c1841db623296cfd49d4a37abd5a3`, сеть `nndata.tbin.compr` из того же commit встроена upstream-сборкой в исполняемый файл.
- Проверка APK: два ожидаемых ARM64-процесса, выравнивание 16 KiB, версии/commit/хеши, лицензии, отсутствие прежних движков и разрешения интернета, затем сертификат.
- Артефакт **Hod-Corresponding-Source** включает точные деревья исходников обоих движков и их сети; приватные ключи и объекты сборки исключены.

Локальная проверка без SDK:

```bash
bash scripts/test-core.sh
python3 tests/test-caissa-build.py
python3 tests/test-signing.py
java scripts/check-java-syntax.java
```

Полная Linux-сборка с установленными инструментами и постоянным ключом: `bash scripts/bootstrap-build.sh`. `-PcompactOnly` разрешён для разработки/раннего lint, он не заменяет полную проверенную сборку.

Метод выбора вариантов: [docs/TRAINING.md](docs/TRAINING.md). Фактическая проверка и ограничения: [docs/VERIFICATION.md](docs/VERIFICATION.md). Проверки на телефоне: [docs/DEVICE-QA.md](docs/DEVICE-QA.md).
