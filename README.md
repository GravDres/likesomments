# ХОД — шахматный помощник для Android

Нативное приложение с плавающим окном, стрелкой поверх доски Chess.com и локальным анализом Stockfish 19 / NNUE. Подготовлено для ARM64, Android 16 и realme Neo 7 SE. Версия 0.3. Минимальная версия Android — 10 (API 29, выбран под актуальный Android-target Stockfish). API нейросети, сервер, ключи и root не требуются. Интернет нужен только при сборке.

Это экспериментальная версия. В этой среде проверено независимое шахматное ядро, геометрия стрелок и обнаружение движения под стрелкой; сборка Android и настоящая тема Chess.com на телефоне ещё не проверены. **4000 Elo и безошибочная игра не обещаются.** Быстрый расчёт даёт лучший найденный движком вариант в выделенное время; более глубокий поиск может изменить оценку. Рейтинг зависит от условий измерения, оборудования и контроля времени — это объясняет [официальная документация Stockfish](https://official-stockfish.github.io/docs/stockfish-wiki/Stockfish-FAQ.html#the-elo-rating-of-stockfish).

## Получить APK через GitHub Actions

1. Создай репозиторий на GitHub с основной веткой `main`.
2. Распакуй архив проекта и загрузи **его содержимое в корень репозитория**. Особенно важно сохранить `.github/workflows/android.yml`. Просто загруженный ZIP не запускает сборку.
3. Открой **Actions → Build Android APK → Run workflow**. Сборка также запускается при push в `main`. Секреты и токены добавлять не нужно.
4. После зелёного результата открой запуск и скачай **Artifacts → Hod-Android-arm64**. Распакуй скачанный артефакт и установи `app-debug.apk` на телефон.

Actions устанавливает Java 17, Gradle 8.13, SDK 36 и NDK r28c; проверяет правила и распознавание на синтетических кадрах; собирает официальный Stockfish с NNUE; собирает APK и проверяет ARM64, вложенные сети, лицензии, выравнивание ELF для страниц 16 KiB и подпись. Второй артефакт `Hod-Corresponding-Source` содержит исходники приложения и точные исходники/сети включённого Stockfish.

У `android-actions/setup-android@v3` явно задано `packages: 'platform-tools'`: это заменяет его устаревший список по умолчанию `tools platform-tools`. Платформа 36, build-tools и NDK устанавливаются следующим шагом. Лицензии принимает сам action; дополнительный конвейер `yes | sdkmanager --licenses` в workflow не нужен. [Описание параметра packages](https://github.com/android-actions/setup-android/tree/v3#additional-packages).

APK подписан отладочным ключом и предназначен для установки вручную. При смене ключа между сборками Android потребует удалить предыдущую установку. Для постоянного распространения нужно настроить собственную release-подпись.

## Первый запуск — автоматический поиск

1. Запусти ХОД и разреши окно поверх приложений и захват всего экрана.
2. Открой начальную расстановку в Chess.com. Помощник сам найдёт границы доски, определит ориентацию стандартных светлых/тёмных фигур и проверит два последовательных кадра.
3. Найденная сетка кратко подсветится. Окно автоматически переместится за пределы доски, затем появится стрелка лучшего найденного хода.

Если результат неоднозначен, приложение предложит уже заполненную рамку и переключатель стороны: проверь их и нажми «Готово». Для повторного поиска открой «+» → «Найти доску». Долгое нажатие этой кнопки открывает запасной ручной режим. На время поиска окно скрывается, чтобы не закрывать клетки; остановить службу можно из уведомления. Если доска не найдена за 18 секунд, появляется сообщение и возможность повторить поиск.

Первое обучение теме требует начальной расстановки. Произвольную середину новой партии приложение не восстанавливает. При повторном поиске в текущем сеансе существующие шаблоны и история сохраняются, если фигуры однозначно распознаны и соответствуют легальному продолжению. После изменения размера экрана поиск запускается автоматически.

Кнопка «Стрелка: вкл/выкл» управляет рисунком, «Глубже · 8 секунд» повторяет расчёт, «Пауза» останавливает обработку, «×» завершает службу. Плюсовая оценка — преимущество белых, минусовая — чёрных. По умолчанию Stockfish 19 работает без ограничения силы и рассчитывает один лучший ход; три варианта можно включить отдельно для разбора. API и подключение к сети готовому приложению не нужны.

На реальном realme автопоиск ещё не проверен. Детектор рассчитан на обычную плоскую доску 8×8 с видимыми чередующимися клетками; необычные темы, перекрывающие окна и неоднозначные цвета могут потребовать проверки найденной рамки.

## Как работает точность

- Обучение по твоей теме: из начальной позиции выделяются шаблоны всех 12 типов фигур. Привязки к одному размеру экрана или заранее скачанной теме нет.
- Сначала нужны два одинаковых распознанных кадра. Затем расположение фигур должно совпасть с текущей позицией или с её легальным продолжением на 1–2 полухода.
- Очередь хода, права рокировки, en passant и счётчики сохраняются по истории ходов, а не угадываются из одного скриншота.
- В режиме наблюдения Stockfish получает всю последовательность ходов от начала партии: так учитываются повторения, которые нельзя восстановить из одного FEN. Для отдельного FEN-разбора прежняя история неизвестна.
- При анимации, неуверенном совпадении, невозможной позиции или окне поверх доски старые подсказки убираются и расчёт отменяется. Показатель «совпадение» — мера сходства шаблонов, а не статистическая вероятность правильности.
- Новый расчёт отменяет предыдущий; результаты старой позиции не попадают в окно. Android-кадры обрабатываются отдельно от движка.
- Стрелка появляется по итоговому ответу `bestmove`, а не по очередному промежуточному варианту поиска. Его легальность проверяется ещё раз.
- Пока стрелка видна, кадры с ней используются только для поиска изменений вне нарисованных пикселей. При движении доски стрелка скрывается; распознавание возобновляется по кадру после скрытия. Сама стрелка не передаётся распознавателю как часть фигуры. Реальную задержку и устойчивость этой схемы нужно измерить на телефоне.

Поддержаны обычные легальные ходы, шах и запрет оставлять короля под шахом, обе рокировки с проверкой атакованных полей, en passant с проверкой вскрытого шаха, все четыре превращения, мат и пат. Отслеживаются повторения и счётчик 50/75 ходов. Автоматически отмечаются пятикратное повторение, правило 75 ходов и стандартные случаи недостатка материала. Трёхкратное повторение и правило 50 ходов дают право заявить ничью; автоматически завершать партию по ним приложение не пытается. Таймер, сдача и решение сервера Chess.com не считываются.

## Android 16 / realme

Используется `MediaProjection` с foreground-службой типа `mediaProjection` и постоянным уведомлением. Токен согласия используется только для одного сеанса. Изменение размеров обрабатывается через существующий virtual display; требуется новая калибровка. Блокировка экрана или системная остановка захвата освобождают ресурсы и закрывают окно.

Если realme UI останавливает службу, открой настройки батареи ХОД и разреши фоновую работу. В приложении есть кнопка перехода к настройкам. Названия пунктов зависят от прошивки. Root не используется; системные ограничения не обходятся.

Кадры остаются в оперативной памяти: без записи, логирования содержимого или сетевой отправки. У приложения нет разрешения `INTERNET`, доступа к файлам других приложений или Accessibility-службы. Основной режим — подсказки; автоматические нажатия не реализованы.

## Проверка и разработка

```bash
# Независимое ядро, нужен JDK 17+; Android SDK не нужен:
bash scripts/test-core.sh

# Полная Linux-сборка со скачиванием инструментов внутрь tools/:
bash scripts/bootstrap-build.sh

# Или при уже установленных SDK, NDK и Gradle:
export ANDROID_NDK_HOME="$ANDROID_HOME/ndk/28.2.13676358"
bash scripts/build-stockfish.sh
gradle :app:assembleDebug
```

Обычная сборка завершается ошибкой, если Stockfish не подготовлен. Для разработки без NDK допустим `gradle -PcompactOnly :app:assembleDebug`: такой APK использует отдельный простой движок «ХОД · компактный», **его сила не соответствует Stockfish**. GitHub Actions всегда собирает полную версию.

Независимые тесты проверяют эталонные числа perft (начальная позиция до глубины 4: 197281, Kiwipete до глубины 3: 97862), особые правила, некорректный FEN, восстановление двух полуходов и шаблонное распознавание на синтетических изображениях. План испытаний на реальном телефоне: [docs/DEVICE-QA.md](docs/DEVICE-QA.md).
