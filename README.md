# ХОД 0.23 · Caissa 2.0 · Android ARM64

Локальный шахматный помощник для тренировок и разбора позиций: автоматическое распознавание доски, история партии, стрелка и устойчивое плавающее окно. Android 10–16; ARM64. Поддерживаются стандартные шахматы и доски официальных приложений Chess.com и Lichess.

## Что изменилось

- Единственный игровой движок — **Caissa 2.0** с официальной нейросетью `eval-ml-8-152B-spsa.pnn`.
- Stockfish, Maia, ONNX Runtime и Tooken API удалены из приложения и сборки. У APK нет разрешения `INTERNET`.
- Старая настройка движка больше не влияет на запуск. Шахматная история, распознавание и положение окна сохраняются при обновлении.
- Загрузка нейросети подтверждается самим процессом Caissa. При ошибке приложение не переключается на слабый движок или расчёт без сети.
- Нет случайного ослабления: `EvalRandomization=0`. Профили меняют время расчёта, не изображают рейтинг человека.
- Отмена поиска дожидается его итогового ответа перед следующим запросом; зависший процесс можно завершить без блокировки интерфейса. Поздние ответы проверяются по версии позиции и поиска.
- Состояние и рекомендуемый ход теперь видны и в развёрнутой панели, над прокруткой.

Помощь программ во время партий с людьми запрещена Chess.com и Lichess. Замена движка не делает её разрешённой или незаметной. Для Chess.com используйте тренировку против встроенного компьютера или разбор завершённой партии. В Lichess правила встроенного AI и сторонних BOT-аккаунтов различаются: https://lichess.org/page/fair-play.

## Настройки для начала

| Настройка | Рекомендация |
| --- | --- |
| 3+2 | Блиц 3+2 — 600 мс расчёта |
| 10 минут | Рапид 10 минут — 1500 мс расчёта |
| Потоки | 2 |
| Память поиска | 128 МБ |
| Варианты | 1; для отдельного FEN-разбора можно включить 3 |
| Положение окна | Закреплено, автоперенос выключен |

Распознавание и проверка кадра добавляют время к бюджету поиска. Нейросеть загружается при создании процесса, а не на каждом ходе. Caissa получает всю известную последовательность ходов с исходным FEN, чтобы учитывать повторы и шахматные права. Память поиска очищается только для новой партии или нового процесса. При восстановлении с середины история до подтверждённого FEN неизвестна.

Рейтинг движка из CCRL не равен рейтингу пользователя Chess.com. Сила и задержки на realme Neo 7 SE ещё требуют измерений; обещаний 2000/3000 Elo нет.

## Обновление из ZIP через Termux

Скачайте `Hod-v0.23-Caissa.zip` в Downloads. Важно выполнить очистку: распаковка ZIP сама не удаляет файлы прежних версий.

```bash
cd "$HOME/hod-likesomments" &&
unzip -o "$HOME/storage/downloads/Hod-v0.23-Caissa.zip" &&
python3 scripts/clean-legacy.py &&
git add -A &&
git commit -m "v0.23: replace legacy engines with offline Caissa" &&
git push origin main
```

`clean-legacy.py` удаляет только перечисленные в нём исходники, модели и библиотеки старых движков. Он не трогает ключ подписи, настройки GitHub или пользовательские шахматные файлы. Очистка повторяется в CI, чтобы старые библиотеки не попали в APK даже после обновления ZIP поверх старого репозитория.

Push запускает **Actions → Build Android APK**. Готовый артефакт — **Hod-Android-arm64**, внутри `app-release.apk`. Подпись прежняя: секреты `HOD_KEYSTORE_BASE64` и `HOD_KEYSTORE_PASSWORD` менять не нужно. Установите APK поверх приложения. При несовпадении сертификата Android откажет в обновлении; не генерируйте новый ключ. Подробности: [docs/SIGNING.md](docs/SIGNING.md).

## Использование

1. Выберите Chess.com или Lichess, свой цвет и профиль времени.
2. Разрешите окно поверх приложений, уведомление и захват всего экрана. При выбранном Root-захвате подтвердите доступ в своём менеджере root.
3. Откройте начальную расстановку. Доска проверяется по двум стабильным кадрам. Расположите окно за пределами доски.
4. Цвет меняется кнопкой «Белые ⇄ / Чёрные ⇄» в заголовке. На чужом ходу стрелки нет.
5. «↘» сворачивает окно в маленькую кнопку; нажатие коня возвращает панель. Перетаскивание кнопки не меняет сохранённое место большой панели.
6. «↻» повторно проверяет доску, распознаёт новую начальную расстановку или продолжает сохранённую партию. «Позиция» помогает восстановить подтверждённый FEN с середины. «+» открывает профиль времени, паузу, повторный поиск и «Глубже · 8 секунд».

Панель сохраняет выбранную позицию. Скрытая стрелка не мешает получению чистых кадров. Если сама панель перекрывает доску, анализ ждёт её перемещения или сворачивания, а не использует закрытые клетки. Потеря захвата оставляет окно с причиной остановки. Принудительное завершение процесса Android или прошивкой невозможно гарантированно предотвратить; разрешите фоновую работу ХОД в настройках realme.

## Сборка и проверки

GitHub Actions: Java 17, Gradle 8.13, Android SDK 36, NDK r28c, CMake 3.31.6. Проверка release lint остаётся включённой.

1. Восстановление постоянного ключа и удаление старых движков.
2. Release lint и локальные тесты правил, распознавания, окна, Root-транспорта и UCI-клиента.
3. Получение официального исходного кода Caissa 2.0: commit `bb725799e9b19ebdaa0d584f5433fc1c3019e349`.
4. Получение официальной сети с проверкой опубликованного GitHub SHA-256 и размера. При отсутствии контрольной суммы сборка останавливается.
5. Сборка Caissa для Linux и настоящие протокольные тесты через Java-клиент: продолжение партии, мат, шах, специальные позиции и отмена поиска.
6. Сборка ARM64 NEON для Android API 29 со статической libc++ и выравниванием ELF 16 KiB.
7. Подписанный release APK, проверка сети, движка, отсутствия старых компонентов и разрешения INTERNET, проверка сертификата.

`Hod-Corresponding-Source` содержит точные исходники приложения, Caissa и сеть; служебные объекты сборки и приватные ключи исключены. APK хранит полный commit, хеши сети и бинарного файла в `assets/caissa/provenance.json`.

Локальная проверка без Android SDK:

```bash
bash scripts/test-core.sh
python3 tests/test-caissa-build.py
python3 tests/test-signing.py
java scripts/check-java-syntax.java
```

Полная Linux-сборка при установленных инструментах и переменных постоянной подписи: `bash scripts/bootstrap-build.sh`. `-PcompactOnly` разрешён только для разработки и раннего lint; он не заменяет проверенную полную сборку.

Результаты и ограничения: [docs/VERIFICATION.md](docs/VERIFICATION.md), проверки на телефоне: [docs/DEVICE-QA.md](docs/DEVICE-QA.md).
