# Что проверено в среде подготовки

- 147 автоматических проверок независимого ядра прошли на Java 21 с исходной совместимостью Java 17.
- Эталонные perft: стартовая позиция 20 / 400 / 8902 / 197281; Kiwipete 48 / 2039 / 97862.
- Особые правила, проверка FEN, право на ничью, сохранение полной позиции при восстановлении двух полуходов.
- Шаблоны фигур на синтетических кадрах: начальная позиция, перемещение на подсвеченную клетку, обе ориентации доски. Две реальные области доски Chess.com проверены отдельным RealBoardTest ниже; работа приложения на устройстве не проверялась.
- UCI-клиент проверен отдельным асинхронным процессом: чтение хода, отклонение нелегального варианта, знак оценки за чёрных, отмена поиска и запуск следующего без старого результата, переключение режимов и выбор итогового `bestmove`, если он отличается от последнего промежуточного топ-варианта. Настоящий ARM64 Stockfish в этой среде не запускался.
- Проверены передача полной истории ходов в UCI и отклонение истории, не соответствующей подтверждённой позиции.
- Проверены координаты стрелки при обеих ориентациях, направления рокировки и en passant, сохранение выбора превращения, игнорирование собственной нарисованной стрелки детектором движения и обнаружение изменения доски под стрелкой на синтетическом изображении.
- XML ресурсов и манифеста, YAML workflow, синтаксис shell/Python проверены.
- Синтаксический разбор всех 27 Java-файлов приложения прошёл. Это не заменяет компиляцию с Android SDK.

Среда не содержит Android SDK/NDK; скачивание инструментов не выполнялось. Поэтому успешная сборка APK, Android API type checking, запуск на Android 16, захват экрана, распознавание Chess.com и устойчивость службы требуют проверки через GitHub Actions и на телефоне. План: [DEVICE-QA.md](DEVICE-QA.md).

Автопоиск: проверены пять размеров/расположений доски при обеих ориентациях, другая палитра с шумом, отсутствие доски, перекрытие диалогом, два неоднозначных поля, проверка двух кадров, повторный поиск с сохранением истории и отказ обучаться по произвольной середине партии. Эти проверки используют синтетические изображения; реальные темы Chess.com требуют испытаний на устройстве.

Изменения 0.4 проверены дополнительно:

- Свой цвет и очередь на последовательности e2e4/e7e5; начальная позиция не выдаёт подсказку за чёрных.
- Два стабильных кадра после неопределённой анимации; один кадр историю не меняет.
- Сериализация и восстановление партии с очередью хода, рокировками, en passant, повторениями и шаблонами темы; продолжение по восстановленной теме.
- Возврат к начальной позиции в существующей партии сохраняет историю; новая несогласованная расстановка требует явного начала новой игры. Повреждённый снимок и нелегальная история отклоняются.
- Обрезанная область доски с ненулевыми экранными координатами сохраняет распознавание и корректную маску собственной стрелки.
- Процесс UCI в тесте требует полного Skill Level, отключённого ограничения силы, Hash=256 после Threads и готовности после ucinewgame.

Не выполнены: замеры силы/задержки на реальном устройстве, проверки realme UI, компиляция Android и запуск настоящего Stockfish. Уменьшение интервала чтения до 160 мс — настройка кода, а не обещание конечной задержки ответа.

Изменения 0.5 проверены дополнительно:

- Граница чистого кадра не зависит от Image.getTimestamp: блокировка на время оверлея, ожидание публикации скрытия, отбрасывание очереди, открытие потока и сброс при замене захвата. Версия границы позволяет отклонить кадр, пересекающий скрытие во время копирования.
- Восстановление однозначной цепочки из трёх и четырёх полуходов, полная позиция и сохранение восстановленной истории на диск.
- Неоднозначный порядок пропущенных ходов отклоняется без изменений истории. Отмена глубокого восстановления возвращает RECOVERY_LIMIT, не записывая частичный результат.

Сохранение панели при MediaProjection.onStop, START_STICKY, foreground specialUse, повторное согласие и ремонт ImageReader требуют Android-сборки и испытаний на realme. Проверки ядра и синтаксиса не доказывают эти свойства на телефоне.

Изменения 0.6:

- 147 проверок CoreTest и 18 проверок RealBoardTest (всего 165). Оба исходных пользовательских JPEG дополнительно проверены напрямую: прежний детектор возвращал null на переданных копиях, исправленный определяет поле около (0,414), размером 581 px на изображении 582×1280. Переданные копии могут отличаться масштабом/сжатием от исходного MediaProjection-кадра на телефоне.
- В репозиторий включены только две области доски 582×582, без панели телефона, уведомлений и пользовательского интерфейса. Разметка расположения фигур проверена вручную. Права рокировки, очередь и счётчики в тесте заданы явно, а не распознаны из изображения.
- Проверены все 64 клетки, чтение второго кадра после обучения по первому, две последовательные проверки текущей позиции и сохранение метаданных. Переход фигур на противоположный фон проверен на производных тестовых пикселях из этих фигур; масштабирование — на трёх размерах.
- Проверены собственный исходный FEN для восстановления, передача последующих ходов в UCI и отклонение неправильной исходной позиции. Старые сохранения версии формата 0.4/0.5 читаются без потери ходов.
- Новые кнопки и окно подтверждения позиции требуют проверки на Android; локально выполнен синтаксический разбор Java, не Android API-компиляция. Настоящий ARM64 Stockfish в этой среде по-прежнему не запускался.
