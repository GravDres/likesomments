# Постоянная подпись ХОД, начиная с 0.17

Сгенерирован отдельный ключ RSA-4096, alias `hod`, формат PKCS12, срок сертификата 10000 дней. Пароль уже создан; вручную придумывать его не нужно. Публичный отпечаток закреплён в `config/signing-certificate.sha256`. Это самоподписанный сертификат приложения Android; покупать сертификат или устанавливать его в системные доверенные сертификаты телефона не нужно.

Скачать два файла из сообщения: `Hod-v0.17-Stable-Signing.zip` и **отдельно** `Hod-Signing-Key.zip`. Оба сохранить в «Загрузки». Архив ключа — личная резервная копия, его нельзя добавлять в публичный GitHub-репозиторий. Он содержит ключ, пароль, публичный сертификат и готовую base64-строку. Рабочая копия на телефоне будет храниться вне проекта в `$HOME/.hod-signing`.

## Однократная настройка в Termux

```bash
pkg install git unzip gh -y
termux-setup-storage
```

Если копии репозитория ещё нет:

```bash
git clone https://github.com/GravDres/likesomments.git "$HOME/hod-likesomments"
```

Из существующей копии:

```bash
cd "$HOME/hod-likesomments" &&
unzip -o "$HOME/storage/downloads/Hod-v0.17-Stable-Signing.zip" &&
bash scripts/setup-signing-termux.sh "$HOME/storage/downloads/Hod-Signing-Key.zip" &&
git add . &&
git commit -m "v0.17: permanent APK signing" &&
git push origin main
```

Если GitHub CLI попросит войти, открой предложенную страницу и подтверди вход своим аккаунтом. Скрипт сам загрузит два репозиторных Actions Secret: `HOD_KEYSTORE_BASE64` и `HOD_KEYSTORE_PASSWORD`. Значения в терминале не печатаются. Он проверяет совпадение публичного отпечатка и не перезаписывает сохранённые файлы ключа. Для другого репозитория вторым аргументом передай `owner/repository`.

В следующих обновлениях эту настройку повторять не надо: распакуй свежие исходники, сделай commit/push. В Actions скачай **Hod-Android-arm64**, распакуй и открой `app-release.apk` → «Обновить». Новые APK всё ещё нужно скачивать; постоянная подпись позволяет устанавливать их поверх предыдущей версии с сохранением данных.

## Первая установка после прежних версий

Для обновления Android проверяет package ID, подпись и версию. ID остаётся `ru.hod.chess`, версия поднята до 17. В дальнейшем номер `versionCode` нужно повышать при выпуске новых версий, а ключ оставлять прежним. Переименование APK не меняет подпись.

Старые сборки подписывались случайным debug-ключом среды сборки. Новый сертификат не может подписать обновление от имени старого: для этого нужен **старый закрытый ключ**, которого нет в APK и в текущих исходниках. При переходе со старой подписи потребуется однократная переустановка, если тот ключ не сохранился. Удаление приложения удаляет его локальные данные; после перехода новые версии с этим ключом ставятся поверх. Данная настройка сама ничего не удаляет на телефоне.

## Как работает Actions

1. После Java восстанавливается keystore из Secrets в `$RUNNER_TEMP/hod-signing/hod-update.p12` с правами 0600. Его сертификат сравнивается с закреплённым отпечатком. При отсутствии/ошибке Secrets сборка прекращается: новый случайный ключ не генерируется.
2. Gradle использует этот ключ и для release, и для debug. Пароль передаётся через окружение, а не текстом в исходниках. Выпускается release APK с подписями v2/v3.
3. `apksigner verify` проверяет APK; его фактический сертификат снова сравнивается с закреплённым. Лишь после этого APK передаётся в артефакты.
4. Временный keystore удаляется завершающим шагом `always()`. Ключ/пароль исключены из Git и публичных исходных ZIP, включая соответствующие исходники движков. Секреты не зависят от срока хранения Actions Cache.

Проверки: `python3 tests/test-signing.py`. Они открывают настоящую временную PKCS12, проверяют повторяемость, неверный пароль/ключ, запрет замены ключа и исключение секретов из ZIP. CLI GitHub и вывод `apksigner` в локальных тестах заменены контрактными заглушками; настоящая подпись APK проверяется в Actions после сборки.

Для локальной Linux-сборки используй тот же ключ:

```bash
export HOD_SIGNING_STORE="$HOME/.hod-signing/hod-update.p12"
export HOD_KEYSTORE_PASSWORD="$(cat "$HOME/.hod-signing/keystore-password.txt")"
bash scripts/bootstrap-build.sh
```
